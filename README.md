# E104A-H2-HVHC

Ứng dụng ôn tập và thi trắc nghiệm kiến thức Hậu cần – Kỹ thuật, phát triển độc lập.

## Công nghệ
- React + Vite
- PWA (cài trên máy tính/điện thoại tương thích)
- Lưu trữ cục bộ ở giai đoạn khởi đầu
- Có thể mở rộng backend đồng bộ sau

## Chạy ở máy phát triển
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Kế hoạch phát triển
1. Khung ứng dụng responsive/PWA
2. Môn học và ngân hàng câu hỏi
3. Luyện tập có giải thích
4. Thi thử (30 câu/30 phút cấu hình mặc định; có thể đổi số câu)
5. Chấm điểm, lưu lịch sử và thống kê
6. Nhập câu hỏi từ Word
7. Quản trị ngân hàng câu hỏi
8. Đóng gói Windows/Android/iOS

Lưu ý: phiên bản khởi đầu dùng dữ liệu mẫu, chưa phải công cụ thi chính thức.
